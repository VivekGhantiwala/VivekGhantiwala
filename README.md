### What I've built

**[DataPilot-AI](https://github.com/VivekGhantiwala/DataPilot-AI)** -- A Python framework that automates the boring parts of data science. Upload a dataset, it handles EDA, preprocessing, trains 10+ ML models, ranks them, and gives you explainable results (SHAP/LIME). Has a Streamlit UI so non-technical people can use it too. Dockerized.

**[FreshConnect](https://github.com/VivekGhantiwala/FreshConnect)** -- MERN stack marketplace connecting local vegetable sellers with hotels and restaurants. Real-time order tracking with WebSocket, in-app chat, seller verification, the whole thing. My college major project.

**[YumYumRank](https://github.com/VivekGhantiwala/YumYumRank)** -- Web app that ranks junk food alternatives by how healthy they actually are. Built with PHP and MySQL. Has a scoring algorithm based on nutritional data and user preferences.
